tema

Remote payload for the ARC Starter Templates WordPress plugin — demo manifest, template documents and images, downloaded on demand at import time.

Point the plugin at this repo: in wp-admin, Starter Templates → Templates repository → Remote base URL:
https://raw.githubusercontent.com/ops147/tema/main
This Pages mirror works too:
Leave the field empty to use the templates bundled with the plugin.
